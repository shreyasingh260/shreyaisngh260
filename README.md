## 🚀 Featured Projects

### 🗄️ [KVStore: Mini Distributed Key-Value Store](https://github.com/shreyasingh260/distributed-kv-store)
`Java` `TCP Sockets` `Concurrency` `JUnit`

A distributed key-value store supporting `GET` / `PUT` / `DELETE` over TCP sockets.
- Handles **50+ concurrent clients with zero data races** using `ReentrantReadWriteLock` and an `ExecutorService` thread pool
- **Consistent hashing with virtual nodes** to partition data across 3 nodes
- Stress-tested with 50 simultaneous clients at **~2,500 ops/sec**
- JUnit test suite covering concurrency edge cases and partition rebalancing

### 🏆 ConnectHours: Faculty Appointment & Office Hours Portal
**Winner, WebSpark 2026 (IEEE)** · `Next.js` `TypeScript` `SQLite` `Recharts`

A role-based Student / Faculty / HOD portal built by a team of 3, where I served as **Fullstack Lead**.
- **Smart conflict-resolution engine** that ranks alternative slots when a booking clashes
- Server-side validation preventing double-booking and past or blocked-slot errors
- **Waitlist auto-fill system** and an explainable **no-show risk-scoring model**
- HOD analytics dashboard (Recharts) for utilization and completion trends
